Linux arm64 paketleme araçları

Bu komutlar Debian/Ubuntu tabanlı Linux derleme sunucusunda çalıştırılır; iPhone uygulamasının içinde çalıştırılmaz. Bu araçlar tek başına IPA üretmez. iOS tweak DEB'i için ayrıca Theos, uygun iPhoneOS SDK ve proje kaynakları gerekir.

sudo apt-get update
sudo apt-get install crossbuild-essential-arm64 dpkg-dev debhelper dh-make fakeroot
Hedef mimari: arm64 · Paketleme aracı: dpkg-buildpackage / dpkg-deb

✦ Gerçek fotoğraf oluştur

Metninden yeni bir görsel üretir. Örneğin “iOS 27 için özgün, tam ekran iPhone duvar kâğıdı; derin lacivert-mor cam katmanlar, ince ışık halkaları, hiçbir yazı veya logo olmasın”. Model yalnızca metin eklemez; görüntüyü üretir.

Görsel oluşturmak için bir görsel API anahtarı gerekir. Sohbet için kullandığın Groq anahtarı görsel üretimi desteklemez.
Kullanılan servis: OpenAI Images API (gpt-image-1). Üretim API hesabındaki erişime ve ücretlendirmeye bağlıdır. Anahtar cihazında saklanır; güvenlik için kişisel API anahtarını paylaşma.

▶ Gerçek video oluştur

Metin açıklamasından video üretmeyi dener. İstenen sahneyi, hareketi, kamera açısını ve atmosferi açıkça yaz.

Video üretimi, hesabında Sora API erişimi bulunmasını gerektirir. Bazı hesaplarda bu uç nokta etkin olmayabilir.
Video üretimi OpenAI video API erişimi gerektirir ve işlem birkaç dakika sürebilir. Groq sohbet anahtarı video üretmez. Servis erişimi yoksa uygulama bunu hata olarak gösterecek; sahte video oluşturmayacak.
